## 🎬 강의자료 · `lecture/`

- `발표자료_통계적추론과회귀분석.pptx` — **86슬라이드**, 각 슬라이드 노트에 강의 대사·배경설명 수록. 뷰어용 **PDF** 동봉.
- **흐름**: EDA→추론 연결 → 표본분포·대수의 법칙·중심극한정리 → 신뢰구간 → 가설검정 → 단순·다중회귀 → 회귀 진단(잔차·공선성) → 설명 vs 예측 → **확인 문제(객관식·서술형)**.
- **관통 서사**: Framingham은 '위험인자(risk factor)' 개념의 발상지 — 오늘의 검정·회귀가 곧 그 위험인자를 발굴하는 절차이고, 그 종착점이 임상 도구 **Framingham Risk Score**입니다.

## 📄 리뷰 논문 · `paper/`

- **To Explain or to Predict?** — Galit Shmueli, *Statistical Science* (2010). [DOI: 10.1214/10-STS330](https://doi.org/10.1214/10-STS330)
- 선정 이유·한 문단 요약: [`paper/논문_선정이유_요약.md`](paper/논문_선정이유_요약.md)
- 요지: **설명(해석)과 예측은 다른 목표** — R²·유의성이 높다고 예측을 잘하는 것은 아닙니다. 과제 §1.8·§2-C(설명이냐 예측이냐)와 직결됩니다.

> 모범답안의 숫자는 `MY_SEED = 2345` 기준입니다. 부트스트랩 CI·CLT 시뮬레이션·train/test 분할은 시드에 따라 달라지므로 **본인 시드 실행값과 일치하는지**로 채점하고, 시드와 무관한 값(상관계수·회귀계수·결측 개수·t검정·오즈비)은 모두 동일해야 합니다.

### 🩺 §1.8 설계 노트 — `diaBP`·`prevalentHyp`는 X에서 뺍니다

예측 파트(§1.8)는 `sysBP`뿐 아니라 **`diaBP`(상관 0.784)와 `prevalentHyp`(상관 0.697)까지 설명변수에서 제외**한 모델을 주 모델로 씁니다. 혈압계를 한 번 대면 수축기·이완기가 함께 나오므로 "`diaBP`는 알고 `sysBP`는 모르는" 상황이 임상에 없기 때문입니다. 셀은 이 두 변수를 도로 넣었을 때 test RMSE가 어떻게 변하는지 직접 재서 비교합니다 (`MY_SEED = 2345`, n = 3,658로 네 모델 동일):

| 설명변수 구성 | test RMSE | sysBP 표준편차(22.03) 대비 | in-sample R² |
| --- | --- | --- | --- |
| 주 모델(둘 다 제외) | **19.204** | 87.2% | 0.316 |
| + `prevalentHyp` | 15.223 | 69.1% | 0.558 |
| + `diaBP` | 12.620 | 57.3% | 0.696 |
| + 둘 다 | 11.620 | 52.7% | 0.736 |

⚠️ **용어**: 이것은 **누수(leakage)가 아닙니다.** 미래 정보가 들어온 것도, test가 train에 섞인 것도 아니기 때문입니다. 정확한 이름은 **같은 구성개념을 잰 변수(same-construct predictor)** 이고, 문제는 성능 부풀리기가 아니라 **예측 과제 자체가 현실에 없는 과제가 되는 것**입니다.
